# Logo V2 Brand Guidelines

**Reference:** Approved blue Blaze Systems branding image supplied 2026-10-20.  
**Brand promise:** “Systems that empower a brighter tomorrow.”  
**Pillars:** People · Technology · Progress.

## Symbol and wordmark
A three-dimensional, ribbon/flame-like **B** symbol colored in electric blues. Pair with uppercase **BLAZE** and smaller, widely tracked **SYSTEMS**. Keep silhouette and proportions consistent; never stretch, rotate, bevel, add a background pattern within the mark, or recolor outside the approved palette.

## Typography
The reference board names **Montserrat**. Use bold or extra bold for the BLAZE wordmark and medium, spaced uppercase for SYSTEMS. The SVG logos contain editable text. Their precise appearance is environment-dependent; obtain appropriately licensed Montserrat font files separately before outlining text. No font binaries are distributed.

## Usage
- Blue/gradient lockup on white/light or Deep Blue backgrounds.
- White and black versions are for one-color reproduction only.
- Minimum **suggested** icon size: 32 CSS px; horizontal logo: 180 CSS px.
- Suggested clear space: 25% of the symbol width on all sides.
- Web and accessibility: provide the accessible name “Blaze Systems.”
- On tiny favicon/toolbar contexts, prefer icon-only over squeezing the full wordmark.
- App icon: navy rounded square background, large centered brand symbol.
